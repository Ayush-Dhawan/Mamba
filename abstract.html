Presentation Architecture Map

DS-BiCrossMamba: End-to-End System Flow

Sequential Walkthrough: Ingestion → Tri-Branch Bifurcation → BiMamba Modeling → Fusion → Triaging

1
Raw Audio Ingestion & GPU Circular Buffer
[B=1, Channels=1, Samples=160,000]
Architecture Action

Ingests 16 kHz live audio into a rolling 10.0-second FIFO buffer advancing at a 2.0-second stride (80% overlap) in GPU pinned memory.

Key Talking Point

Zero-copy DMA transfer keeps ingestion latency < 5 ms. The 80% overlap guarantees short 1-second synthetic splices never fall between evaluation cuts.

BRANCH A · Physical Stream
Linear STFT [1025 × 1000]

GPU STFT (N_fft=2048, H=160). Extracts magnitude spectrum up to 8 kHz Nyquist limit.

1x1 Projection [1000 × 256]

Conv2d(1025→256) + BatchNorm + GELU. Standardizes channel depth to d_model=256.

BiMamba Sweep O(N) Scans

Forward pass (with state carryover) + Backward pass (zero-init). Input-dependent noise gating (B_t→0).

Target Artifacts

Vocoder grid lines, high-frequency phase seams, and uncompressed artifacts above 4000 Hz.

BRANCH B · Perceptual Stream
Log-Mel Filterbank [128 × 1000]

Multiplies magnitude by 128 Mel filters + log compression to mimic the human cochlea.

1x1 Projection [1000 × 256]

Conv2d(128→256) + BatchNorm + GELU. Unifies perceptual features to d_model=256.

BiMamba Sweep O(N) Scans

Forward pass (tracks prosodic drift) + Backward pass (local context). Isolates speech channels.

Target Artifacts

Vocal tract formants, prosodic rhythm errors, unnatural pauses, and pitch transitions in 0–4000 Hz range.

BRANCH C · Sub-Band Stream
Learnable SincNet [70 × 1000]

70 parametric bandpass filters operating on raw PCM to isolate dynamic sub-bands.

2D-AttM Masking [1000 × 256]

Spatial attention gate suppresses non-vocal pauses; projects 70 sinc bands to d_model=256.

BiMamba Sweep O(N) Scans

Bidirectional waveform modeling with linear complexity, avoiding quadratic Transformer overhead.

Target Artifacts

Time-domain phase jumps, wave oscillation glitches, and frame-boundary errors lost during STFT conversion.

3
Mutual Cross-Attention (MCA) & Squeeze-and-Excitation Gating
Fused Latent Tensor Z ∈ [B, 1000, 256]
MCA Negotiation Logic

Symmetric cross-queries: Linear stream verifies if high-frequency spikes match vocal tract formants (Q_lin ↔ K_mel/V_mel); Mel stream checks if prosodic flaws align with physical vocoder seams.

The SE Fail-Safe Mechanism

Under room replay or VoIP codec loss, high frequencies die first. The SE gate automatically down-weights linear channels (g_lin→0) and shifts reliance to resilient Mel prosodic channels (g_mel→1).

4
Attentive Pooling, MLP Classifier & Real-Time EMA Smoothing
Z [1000, 256] → Global Vector z [256] → Real-Time Score S_t ∈ [0, 1]
Attentive Pooling & Classifier

Attention weights allow brief 200ms synthetic word splices to dominate global vector z. Regularized 2-layer MLP head outputs window spoof probability P_k.

Gaussian & Asymmetric EMA Filter

Gaussian bell curve suppresses window truncation edges. Asymmetric EMA reacts in < 200ms on attack (α=0.75) and decays slowly (α=0.15), preventing pauses from clearing active alerts.

5
Zero-Day k-NN Retrieval, Telemetry Fusion & Triaging Matrix
Score S_t + Vector Distance d_kNN + Session Telemetry
Zero-Day Retrieval (FAISS)

Vector z queries an in-memory vector store of zero-day spoof clusters, delivering instant protection against unseen voice engines without waiting for model retraining.

Multi-Factor Suppression

Fuses acoustic score with carrier ANI spoof validation, mobile cell tower routing, and SIM swap status to eliminate false alarms on legitimate calls.

GREEN ZONE (S_t < 0.30)

Silent pass. Displays green "Verified" badge on agent UI. Call proceeds with 0% friction.

YELLOW ZONE (0.30 ≤ S_t ≤ 0.80)

Contextual check. Clean telemetry → suppress silently. Ambiguous → automated in-app FaceID/OTP step-up.
